# HireBotics

## Overview

HireBotics provides a comprehensive recruitment experience:

- **For Candidates:** Take proctored AI-assisted interviews, receive instant interview analysis, generate questions from resumes, check ATS (Applicant Tracking System) scores, and get notified about interview calls, rejections, or job alerts.  
- **For HR:** Manage recruitment via a dashboard, create and post hiring opportunities, view candidates who applied, and track ongoing job posts.

---

## Features

### Candidate Portal

- Dashboard with personalized overview  
- Proctored interview with real-time warning system  
- AI-powered interview analysis  
- Resume-based question generation  
- ATS score checking  
- Job alerts page showing recent hirings  
- Notifications for interview calls and rejections  

### HR Portal

- Dashboard for hiring management  
- Create job posts and manage existing posts  
- View candidate lists for specific positions  
- Track active and past job posts

## Technologies Used

- **Frontend:** Vite, React, TypeScript, Tailwind CSS, shadcn-ui  
- **Backend & Cloud:** Firebase (Authentication, Firestore, Cloud Storage)  
- **AI & Machine Learning:** Google Gemini API, custom ML models  
- **Other Tools:** Node.js, npm

```bash
